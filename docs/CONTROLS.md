# Controls

Potato Horde input cheat sheet (current GameScene).

## Always

| Input | Action |
|-------|--------|
| **WASD** / **Arrow keys** | Move |
| Touch / mouse drag | Virtual joystick (bottom-left) |
| — | Weapons auto-fire (no shoot button) |

## Combat run

| Input | Action |
|-------|--------|
| **P** | Pause / unpause |
| **Esc** | Return to Menu |
| **R** | Dev respawn (reset run at arena center) |
| **1** | Spawn melee enemy |
| **2** | Spawn ranged enemy |
| **3** | Spawn blob enemy |
| **5** | Spawn 50 melee in a ring |
| **X** | Grant large XP burst |
| **V** | XP vacuum (~4 seconds) |
| **B** | Force Brute boss |
| **Y** | Force ally drop near player |

## Level-up draft

| Input | Action |
|-------|--------|
| **1 / 2 / 3** | Pick card |
| Click card | Pick card |
| **R** / reroll label | Reroll (if charges left) |
| **Esc** | Does nothing (draft stays open) |
| **P** | Ignored while drafting |

## Menus

| Screen | Input | Action |
|--------|-------|--------|
| Menu | Enter / Space / click Start | Start run |
| Result | Enter / click Retry | New run |
| Result | Esc / click Menu | Menu |
