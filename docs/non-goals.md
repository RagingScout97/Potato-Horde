# Non-goals (v1)

Explicitly **out of scope** for the first ship:

- Multiplayer / co-op / PvP  
- Guilds, clans, social chat  
- Real-money IAP or gacha paywalls  
- Ads / interstitial monetization  
- Final production art (sprites, VFX polish beyond colored boxes)  
- Server backend / accounts (localStorage only)  
- Soft-locks that require payment to continue  
- Console / native stores (browser static host only)

If a feature is not needed for Gates 0–22, do not implement it early.
