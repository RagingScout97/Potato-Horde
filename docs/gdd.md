# Potato Horde — One-Page GDD

**Working title:** Potato Horde  
**Genre:** Top-down survivors-like / roguelite shooter (Zombie.io-style)  
**Platform:** Browser (desktop first, touch later) · single-player only

## Core fantasy

You are a lone survivor in an endless potato-zombie horde. You **only move**; weapons **auto-aim and auto-fire**. Kill → collect XP → draft skills → grow a ridiculous build → survive longer each run.

## Win / lose

| Mode | Win | Lose |
|------|-----|------|
| Chapter | Survive timer **T** and kill the chapter boss | HP ≤ 0 |
| Endless | No win — beat personal best time / score | HP ≤ 0 |

On death: run summary → rewards (banknotes) → retry or hub.

## Session length

- **Target run:** 5–12 minutes for early chapters; endless can go 15–30+.
- **Time-to-fun:** under 10 seconds from boot to moving and shooting (once combat ships).

## Control scheme (T002)

| Input | Action |
|-------|--------|
| WASD / Arrow keys | Move (normalized diagonal) |
| Virtual joystick (touch) | Move |
| P | Pause / unpause |
| Esc | Close modal / pause (later) |
| Mouse aim-to-pointer | **Off by default** |

Weapons fire automatically toward nearest enemy in range. No manual shoot button in v1.

## Core loop (30-second pitch)

1. Move through a large arena while weapons auto-fire.  
2. Kill zombies → yellow XP orbs magnet toward you.  
3. Level up pauses the world → pick **1 of 3** skill cards.  
4. Stack weapons, stats, allies; maxed skills can **Breakthrough** into evolutions.  
5. Survive waves / chapter boss, or push endless scaling until death.  
6. Spend banknotes in the hub on gear and heroes between runs.

## Pillars

- Move-only control, auto combat  
- Variable skill drafts every level  
- Horde pressure + bosses  
- Meta drip (gear, heroes, currencies) without paywalls  

## Non-goals (v1) — see also [non-goals.md](non-goals.md)

No multiplayer, guilds, IAP, ads, or final art.
